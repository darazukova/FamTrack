### Описание таблиц

| Таблица | Назначение | Ключи |
|---|---|---|
| `user_roles` | Роли пользователей (Родитель, Ребенок) | PK: `role_id` |
| `users` | Члены семьи, пользователи системы | PK: `user_id`, FK: `role_id` → `user_roles` |
| `categories` | Категории расходов (Продукты, Транспорт и др.) | PK: `category_id` |
| `expenses` | Расходы членов семьи | PK: `expense_id`, FK: `user_id` → `users`, FK: `category_id` → `categories` |

### Связи

- `user_roles` → `users`: **1:N** (одну роль могут иметь несколько пользователей);
- `users` → `expenses`: **1:N** (пользователь совершает много расходов);
- `categories` → `expenses`: **1:N** (в одной категории много расходов).
